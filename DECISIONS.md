Format: date · who · decision · why.

- 2026-11-15 · P1 · **Pydantic is the source of truth for contracts.** `contracts/schemas/*.json` are generated by `python contracts/gen_schemas.py`; a test fails if they drift. Pydantic emits JSON Schema **2020-12**, not Draft 7 as §4.1 says. The difference doesn't matter for our shapes (no `$defs`-vs-`definitions` consumers yet). Tell P1 if the TS side needs strict Draft 7.
- 2026-11-15 · P1 · **`VerifyRequest.approve_big_rewrite: bool = false`** added. §3 says "BLOCK if big_rewrite **unapproved**", so the approval needs a field. The extension sets it after a human approves a large rewrite and re-submits.
- 2026-11-15 · P1 · **`Verdict.decision_reason`** (string) added so BLOCK always carries a plain-English reason (DocSync lesson: make failures loud).
- 2026-11-15 · P1 · **Sandbox default = local temp dir**, with Docker (`--network none`) opt-in via `PCP_SANDBOX=docker`. The local sandbox only denies network on a best-effort basis (proxy vars cleared); real isolation needs Docker.
- 2026-11-15 · P1 · **Baseline run = original source + the patch's test-file hunks.** That's the only way new F2P tests can actually *fail* on old code.
- 2026-11-15 · P1 · **LLM providers are pluggable** (OpenAI-compatible HTTP + a scriptable `fake` provider). Real models to be chosen once the TrueForge docs are confirmed.
